# JeliXora Privacy Policy

**Last updated:** September 28, 2026

This Privacy Policy explains how the **JeliXora** mobile game, developed by VictoriumSoft, handles user data.

**App name:** JeliXora  
**Package name:** com.victoriumsoft.jeliXora  
**Developer:** VictoriumSoft

## 1. Personal data collected

In its current version, JeliXora does not request or transmit to developer servers personal information such as name, email address, phone number, precise location, contacts, photos, camera data, microphone recordings, or similar personal data.

The app does not currently provide a user account or sign-in system.

## 2. Data stored on the device

To maintain game progress and preferences, the app may store certain information locally on the user's device, including:

- Level progress and unlocked stages
- Stars, scores, and achievements
- In-game coins and booster inventory
- Daily rewards and quest progress
- Language preference
- Sound and music settings
- Text size
- Accessibility settings such as high contrast, color assist, haptics, and reduced motion

In the current version, this information is not transmitted to developer servers.

## 3. Internet connectivity

The core game can operate without an internet connection.

The current version does not use an active analytics, advertising, or behavioral profiling SDK to track users.

If future versions add advertising, analytics, cloud saves, or online functionality, this Privacy Policy will be updated before that version is released.

## 4. Advertising and third-party services

The current version does not have an active third-party advertising SDK. The app may contain placeholder code for features such as rewarded ads, but those placeholders do not themselves collect user data or transmit information to an advertising network.

If Google AdMob or another advertising service is enabled in a future version, the relevant data-processing and privacy disclosures will be added to this policy.

## 5. Children's privacy

The current version of JeliXora does not include a system designed to knowingly collect personal data from children.

If the app is later published specifically for children or directed to children, additional protections will be implemented in accordance with applicable store policies and child-privacy requirements.

## 6. Permissions

The current version does not require access to precise location, camera, microphone, contacts, or private user files for its core gameplay.

Device haptic/vibration feedback can be enabled or disabled by the user in the app settings.

## 7. Data sharing

Because the current version does not collect personal information on developer servers, personal user data is not sold, rented, or shared by the developer with third parties.

## 8. Data security

Locally stored game data is protected primarily by the device operating system and the application's local storage mechanisms.

Local game data may be lost if the application is uninstalled, its storage is cleared, or the device is reset.

## 9. Data deletion

Because there is no account system, there is no user account stored on a developer server to delete.

Users can remove local game data by:

- using the in-app **Reset Save** option,
- clearing the app's data from Android settings, or
- uninstalling the application.

## 10. International users

JeliXora may support many languages and regional language variants. In the current version, personal user data is not transferred to developer servers, so no personal data is transferred internationally by the developer.

## 11. Changes to this policy

This Privacy Policy may be updated when new features, third-party SDKs, online services, or data-processing functionality are added.

The **Last updated** date will be revised when meaningful changes are made.

## 12. Contact

For privacy-related questions, users may use the **VictoriumSoft developer contact information shown on Google Play**.

Before publication, adding a direct support/privacy email address to this section is recommended.

---

This policy reflects the **current data-handling behavior** of JeliXora. If advertising SDKs, analytics, user accounts, cloud saves, online multiplayer, or other third-party data services are added, this policy should be updated before release.
